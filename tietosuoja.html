Privacy policy

Tietopyynnöt is a private tool used only by its owner. It requests the Gmail scope gmail.readonly and only for the owner's own Google accounts.

What data is accessed

Email messages and their metadata in the owner's own Gmail account, read-only. The tool never sends, modifies or deletes email.

How it is used

Messages related to the owner's GDPR requests are stored to track replies and statutory deadlines. Data is not used for advertising, profiling or AI model training.

Storage and sharing

Data is stored encrypted on the owner's own server. It is not sold, shared or transferred to any third party.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, after which stored copies are deleted by the owner.

Google API Services User Data Policy

Tietopyynnöt's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
